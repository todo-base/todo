# Виды

Хранилище может доставлять два вида данных: origin и view.

Origin - это исходные данные по issues, наборам, их атрибутам и т.д. К ним применяются правила непротиворечивости, несовпадения или определения единственного источника правды.

View же даёт представление уже существующих исходных данных. Он может переопределять атрибуты, состав наборов и некоторые другие параметры.

Например, общий список задач в хранилище - это origin-данные. А текущее размещение задач на доске - может быть view. План с выбранными задачами на спринт - также может быть представлен отдельным view.

Разные view могут по-разному представлять одни и те же origin-данные.

## Поддержка видов в tracker-fs

Файловый трекер должен чётко отделять origin-данные от view. Для этого используется атрибут `source_type`, который обязателен к установке для view:

```md
---
source_type: view
group_by: status
---

# ToDo
...

# In Progress
...
```
Варианты укаания в пути: `TODO.view.md` или `view/TODO.md`.
